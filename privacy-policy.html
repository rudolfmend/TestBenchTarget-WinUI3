TestBench Target

Privacy Policy

Last updated: August 16, 2026

Overview

TestBench Target is a Windows test application designed for developers and testers who need a predictable target for UI automation, accessibility, monitoring, and interaction testing.

The application does not use analytics, advertising, tracking technologies, or a remote backend. It does not require an account, and it does not transmit personal data to the developer or to a remote service.

Local operation and data

TestBench Target operates locally on the user's Windows device. The Data Entry functionality may save data locally in the application's Windows LocalState storage.

Users may choose to enter real personal information into test fields, but the application is intended for testing purposes and the use of synthetic or non-sensitive test data is recommended.

Diagnostic logging

The application may create a local diagnostic log named TestBenchTarget.log. The log is intended to support troubleshooting and repeatable testing.

The log may contain application events, diagnostic information, operation results, selected control values, text lengths or counts, and error details. TestBench Target is not designed to record the full contents of free-text fields or password fields in the diagnostic log.

The diagnostic log remains on the local device and is not automatically transmitted to the developer or to any remote service. A user may choose to export or share diagnostic information manually.

Network access and third-party services

TestBench Target does not use a remote backend, telemetry service, analytics service, advertising network, or user-tracking service.

The application may open a privacy-policy webpage or another external webpage only as a result of an explicit user action. The external site or browser used to display such a page may be subject to its own privacy practices.

Data retention and deletion

Locally stored application data and diagnostic information remain on the user's device until removed by the user, by application functionality, or as part of uninstalling or resetting the application, subject to normal Windows behavior.

Children's privacy

TestBench Target is a general-purpose developer and testing utility. It does not intentionally collect personal information from children or from any other users.

Changes to this policy

This privacy policy may be updated if the application's functionality or data practices change. The current version will be published at this location.

Contact

For privacy-related questions concerning TestBench Target, contact info@offisen.app.
